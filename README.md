# 🪙 Crypto Hunter

**Crypto Hunter** is a modern web application that allows users to track real-time prices of cryptocurrencies with a clean and responsive UI.
![image](https://github.com/user-attachments/assets/c9dd2ea0-9447-4dcf-b472-53989f726362)

---

## 🚀 Features

- 📈 View current prices of top cryptocurrencies
- 🔍 Search functionality by coin name
- 🌐 Live data fetched from a crypto API
- 💡 Responsive and user-friendly interface
